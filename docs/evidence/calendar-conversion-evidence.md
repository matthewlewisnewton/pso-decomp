# Calendar conversion recovery

`fn_801E283C` (0x801E283C–0x801E2A44) converts an unsigned seconds count into the existing `DateStamp` layout. Its stores establish the year at offset 0, month/day at 2/3, hour/minute/second at 4/5/6, weekday at 7 and the result of `calc_day_in_cycle` at 8. The save-file caller at 0x801E21A8 supplies the seconds from `CARDStat::time` and copies these fields into its result. Both sides now use the same declaration.

The original copies the ordinary twelve-entry nonleap month-offset table at 0x80449700–0x80449730 to the stack. The inverse conversion, `DateToSeconds` at 0x801E2B24, similarly copies a separate table at 0x804496D0–0x80449700. Assigning the first table to the former standalone `text_801E283C` split creates a cyclic object order: the conversion precedes the inverse in `.text`, but its table follows the inverse's table in `.rodata`. The combined `pso_date.cpp` unit represents both orders naturally: code at 0x801E283C–0x801E2D1C and data at 0x804496D0–0x80449730, with the inverse table defined first. Its six previously source-linked functions and table remain part of the combined unit. This establishes a compatible unit boundary, not an original filename or complete ownership of the retained system helpers.

The source retains the executable's unsigned arithmetic and simplified `year % 4` rule, including its treatment of century years. Raw day-of-year and normalized calendar day are separate values. Both conversions use native `DateStamp *` interfaces. The original reference census for `calc_day_in_cycle` contains only the call within this unit; replacing its former `long *` boundary requires no external caller adapter. Its seconds output also uses the declared `int` type directly.

With the same source and flags, GC/2.5, GC/2.6 and GC/2.7 move the month-field store ahead of the table lookup. GC/1.3.2 retains the original order and also matches the six existing functions, so the combined unit has an explicit compiler exception. The table aggregates preserve the original stack copies. Disabling propagation for the conversions preserves the division sequence. These are demonstrated matching constraints, not proof of the original source spelling or pragmas. Complete code, table data, section layout and relocations are checked together before source linkage.
