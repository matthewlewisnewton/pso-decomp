# GC/2.0 migration after merging current main

The migration merges fork main
`f9b6cf76d9` into `codex/gc20-default`; merge commit
`ed5eaca9cd21b4e8cd880d6fd66b0f2126b850ff` records the conflict resolution.
This note supersedes the current-state counts in the
[initial adoption record](compiler-default-gc20-adoption.md), whose baseline
was `08c178922f`. That earlier experiment remains historical evidence.

## Final configuration and merge scope

GC/2.0 is the default compiler and linker. Every former GC/2.6 assignment
uses GC/2.0 except four game units with GC/1.3.2 matching profiles:

- `pso/network/TProtocol.cpp`
- `pso/object/TObjTombstone.cpp`
- `pso/object/TObjResultWin.cpp`
- `pso/misc/TPlyMeetUserExtension_801DAC6C.cpp`

The earlier nine experimental GC/2.0-to-GC/1.3.2 assignments are withdrawn.
Those units now inherit GC/2.0, preserving their effective main compiler
while eliminating unnecessary overrides. Their unchanged source/flag
profiles are covered by the fresh main comparison. Other existing library
and game compiler profiles remain unchanged.

Independent resolution of all 3,620 ordered configuration entries against
fetched main verifies:

- 3,379 GC/2.6 entries change to GC/2.0.
- Four GC/2.6 entries change to GC/1.3.2.
- No other effective compiler changes occur.
- Source paths, object order, link status, flags, symbol mappings, alignment
  adjustments and every other resolved noncompiler object option remain
  identical to main.
- The linker changes from GC/2.6 to GC/2.0; no GC/2.6 assignment remains.

Configured entry counts are GC/2.0: 3,392; GC/1.3.2: 25; GC/1.3: 59;
GC/1.2.5n: 134; GC/1.2.5: 10. These are configuration counts, including
assembly entries, not a count of C/C++ compiler invocations. Five compiler
versions remain; this PR retires GC/2.6 rather than claiming the proposed
three-version endpoint is complete.

Main's newly recovered code and flags are preserved, including CRI's
per-unit inlining/string settings and the De Rol Le `-inline on` profile.
Main already completes De Rol Le at 110/110 exact functions under GC/2.0
and links it from source. The earlier 108/110 count and nonexact-score
improvement therefore do not describe this merged change. De Rol Le now
inherits its existing compiler while retaining its main flags.

Relative to fetched main, no source, header, split, symbol, linkset, retention
or tool implementation changes are included. The PR consists of compiler
selection, documentation and the regenerated compiler-exception inventory.
