# Indirect controller recovery

The native construction groups the manager destructor at 0x802A81B8, its
constructor/registration functions, the indirect rendering helpers and the
controller through 0x802A9284. The two preceding scene routines remain in their
original fragment. This is an evidence-backed unit fold, not a claim about the
original translation-unit filename.

`TEffIndirectCtrl::run_task` at 0x802A88B0 snapshots three native nonvirtual,
no-argument member pointers before dispatch. Their order is scroll,
update-and-flush, then wave update. The receiver remains the controller; the
recipe mode is checked before the indirect call. The source preserves the guard,
signed recipe bytes, unsigned phase accumulation, floating point multiplication
order, standard integer `rand` result and final update flag. It uses the
compiler's member-pointer representation rather than encoding it.

GC/2.0 with the inherited game flags and `-inline off,deferred` emits the original
23 functions and 4,300 text bytes, with the same 149 resolved text relocations.
Deferred generation reverses the source definitions while preserving native
initializer, conversion-pool and vtable order. The native 112-byte read-only
block, 84-byte initialized data block and eight-byte small constant block match
the original addresses and data. These 204 bytes describe the native ranges;
they are not automatically 204 newly recovered bytes.

The manager has a real `TUnk_804DDF04(s32, TObject*)` constructor and inherited
`TObject` allocation. Its four callers use native `new` expressions, preserving
the original allocation and null checks. The constructor matches all 80 original
bytes and registers the full incoming kind; the stored kind is one byte at
0x1C. The native destructor retains the original 88 bytes. Layout assertions and
the native constructor/destructor stores establish its 0x20 size and inherited
vptr at 0x18. Its original class name is unresolved.

The exported tile buffer remains `u32`, matching its separate allocation/free
owner. The static player helper keeps its six-argument interface. Full-width
kind lookup compares the low byte; the setup and wave helpers have void return
types, and the scroll helper narrows its full-width amplitude inside the callee.

The texel helper uses one canonical `u32(u8, u8, u32)` interface. Its formula
uses only bits 0..7 of each coordinate; unsigned width and result arithmetic are
unchanged. The byte inputs retain the original caller conversions without an
incompatible return declaration, function-pointer cast or wrapper. The manager
children created by the explosion routines receive the actual explosion task's
`TObject` base, through `TUnk_804CCB28`.

This private implementation remains a draft. The folded unit needs its own
closed compiler-profile admission before actual graph preparation or full
builds. Anonymous pool export/localization, real regenerated split proof,
source selection and normal no-loss/link gates remain required. No
source-selection promotion or relaxed validation is included.
