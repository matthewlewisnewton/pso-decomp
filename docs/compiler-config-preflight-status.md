# Per-unit compiler configuration preflight — incomplete proposal

The standalone static shape checker recognizes only the Ancient01 exception's inherited GC/2.6 deferred-inlining profile and literal GC/2.0 deferred-inlining profile. It compares complete raw configuration bytes outside the reviewed entry and its contiguous comments, parses without executing code, rejects duplicate or computed dictionary keys and unsupported expressions, and reports hashes of the complete inputs and entry spans. The exact three incremental and cumulative shapes described in the independent plan can be inspected with this helper.

**This file is not an admission mechanism.** Existing configuration rejection in the queue and acceptance validator remains unchanged. The helper does not yet authenticate a review packet, bind Git trees, heads, modes or tool identities, check an actual compile graph, or run under the preparation lock. Do not install or call it as an authorization to execute candidate configuration. Before this work can be reviewed for deployment, the operator-selected pinned packet, CLI integration, lock-held preflight and preparation receipts, acceptance adapter revalidation, and the remaining end-to-end security tests must all be implemented. The strict raw-loss and padding checks must not be relaxed.
